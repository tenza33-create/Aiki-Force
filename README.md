# Aiki-Force

Web estatica para documentar y compartir el sistema Aiki-Force.

## Estructura

- index.html: estructura principal de la pagina.
- styles.css: identidad visual y responsive.
- app.js: renderizado, filtros y busqueda.
- temario.js: contenido editable del sistema y del temario.

## Como actualizar el contenido

1. Abre temario.js.
2. Edita el objeto AIKI_FORCE.
3. Anade nuevas secciones dentro de syllabus o amplia las existentes.

## Como compartirlo

Puedes abrir index.html directamente en el navegador o publicarlo en GitHub Pages, Netlify o cualquier hosting estatico.
